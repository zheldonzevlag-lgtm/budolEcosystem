Forensic Identity Resolution

Correcting Actor Attribution in the Budol Ecosystem Audit Trail

Purpose & Rationale

During a forensic review of the Audit Trail, it was identified that USER_LOGOUT events were displaying the staff member's email address instead of their authorized full name. This violated BSP Circular 808 and PCI DSS 10.2.1 requirements for individual accountability and clear forensic traceability.

The root cause was a UUID mismatch between the SSO Provider (BudolID) and the Admin Application (BudolPay), leading to failed database joins during session termination.

Implementation Progress

✅ Phase 0: Analyze UUID mismatch between SSO and Admin Database
✅ Phase 1: Implement fallback email lookup in Logout Route (v45.2)
✅ Phase 2: Implement UUID mirroring in SSO Callback sync
✅ Phase 3: Verify Actor Identity resolution for Audit Trail
✅ Phase 4: Created feat/forensic-identity-fix branch & Push to Release
✅ Phase 5: Automated Testing via Jest (Auth Suite)

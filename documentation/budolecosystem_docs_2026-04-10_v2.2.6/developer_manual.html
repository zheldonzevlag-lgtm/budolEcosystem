Developer Manual: Identity Resolution v45.2

This document explains the code changes made to ensure consistent actor attribution across the Budol Ecosystem.

1. Logout Identity Mapping Fix

File: budolpay-0.1.0/apps/admin/app/api/auth/logout/route.ts

Previously, the logout route used the sub claim from the SSO token directly. Because the SSO database and the Admin database had different UUIDs for the same emails, the lookup failed, resulting in fallback to the email address in the logs.

The fix implements a dual-lookup strategy:

const user = await prisma.user.findFirst({
    where: { 
        OR: [
            { id: ssoUserId },
            { email: email }
        ]
    }
});

2. SSO Callback Sync Upgrade

File: budolpay-0.1.0/apps/admin/app/api/auth/callback/route.ts

To prevent future mismatches, the sync logic now mirrors the SSO UUID during local account provisioning:

localUser = await prisma.user.create({
    data: {
        id: ssoUser.id, // v45.2: Ecosystem synchronization
        email: ssoUser.email,
        ...
    }
});

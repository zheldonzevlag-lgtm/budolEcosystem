Task List: Fix /api/upload 500 Error

Date: 2026-06-08

Issue: 500 Internal Server Error (FUNCTION INVOCATION FAILED) during image upload to Cloudinary via Vercel.

Implementation Phases

  • Phase 0 - Baseline & Risk Analysis: Identified that `image instanceof File` fails in Vercel Node runtime for NextJS FormData.
  • Phase 1 - Architecture & Data Contracts: N/A (Bug fix).
  • Phase 2 - Backend & API Implementation: Modified `/api/upload/route.js` to use `typeof image === 'object' && typeof image.arrayBuffer === 'function'` and added safe `isSVG` string checks.
  • Phase 3-10 - Testing & Documentation: Created this task list and documented the fix. Testing is done manually by the developer on the dev environment before deployment.
  • Phase 11 - Push, Commit, Create new branch: Wait for user to push to Vercel production.

Technical Details

When Next.js parses `multipart/form-data` in a serverless Edge or Node runtime, the resulting `File` object from `FormData` might not satisfy the `instanceof File` check due to cross-realm or polyfill differences (e.g., `undici`'s `File` vs global `File`).

If the check fails, the object is passed down as an object, causing `image.startsWith` to throw a `TypeError: image.startsWith is not a function`. This unhandled exception crashes the Vercel function, returning a `FUNCTION INVOCATION FAILED` 500 HTML response instead of a JSON response.

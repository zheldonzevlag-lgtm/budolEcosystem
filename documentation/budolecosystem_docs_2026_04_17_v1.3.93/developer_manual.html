🛠️ Developer Manual — v1.3.93

Technical reference for the geocoding fallback implementation. Branch: release/1.3.93

Overview

This release introduces a platform-agnostic geocoding layer to support address resolution across Android, iOS, and Flutter Web. The implementation wraps the native geocoding package with an OSM Nominatim REST API fallback.

  • Primary resolver: Flutter geocoding package (native Android/iOS Google Play Services)
  • Fallback resolver: OpenStreetMap Nominatim REST API (works on Web, emulators, CI)
  • HTTP client: package:http (already a dependency)

Key Method: _geocodeAddress(String query)

What it does: Converts a typed address string into map coordinates. Why: Native geocoding fails on Web. Nominatim provides a universal fallback.
Future<void> _geocodeAddress(String query) async {
  if (query.isEmpty) return;
  setState(() => _isLoading = true);
  try {
    LatLng? resultLatLng;

    try {
      // PRIMARY: Try native OS geocoding (works on Android/iOS physical devices)
      List<Location> locations = await locationFromAddress(query);
      if (locations.isNotEmpty) {
        resultLatLng = LatLng(locations.first.latitude, locations.first.longitude);
      }
    } catch (_) {
      // FALLBACK: Native failed (Web/emulator) — use OSM Nominatim REST API
      final url = Uri.parse(
        'https://nominatim.openstreetmap.org/search'
        '?q=${Uri.encodeComponent(query)}&format=json&limit=1'
      );
      final response = await http.get(url, headers: {'User-Agent': 'budolPayApp/1.0'});
      if (response.statusCode == 200) {
        final data = json.decode(response.body) as List;
        if (data.isNotEmpty) {
          resultLatLng = LatLng(
            double.parse(data[0]['lat']),
            double.parse(data[0]['lon']),
          );
        }
      }
    }

    if (resultLatLng != null) {
      final loc = resultLatLng;
      setState(() { _selectedLocation = loc; });
      _mapController.move(loc, 15.0);         // Reposition map camera
      await _reverseGeocodeCoordinate(loc);   // Auto-fill the search bar
    } else {
      throw Exception('Location not found');
    }
  } catch (e) {
    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Address not found')),
      );
    }
  } finally {
    if (mounted) setState(() => _isLoading = false);
  }
}

Key Method: _reverseGeocodeCoordinate(LatLng latLng)

What it does: Converts map coordinates into a human-readable street address, filling the search input. Why: Called on every tap/pin drop/GPS snap so the user always sees what address they pinned.
Future<void> _reverseGeocodeCoordinate(LatLng latLng) async {
  try {
    try {
      // PRIMARY: Native reverse geocoding
      List<Placemark> placemarks = await placemarkFromCoordinates(
        latLng.latitude, latLng.longitude,
      );
      if (placemarks.isNotEmpty) {
        final p = placemarks.first;
        final address = [p.street, p.subLocality, p.locality,
                         p.administrativeArea, p.country]
            .where((part) => part != null && part.isNotEmpty)
            .join(', ');
        if (address.isNotEmpty) {
          _searchController.text = address;
          return; // Done — no fallback needed
        }
      }
    } catch (_) {
      // Native failed — fall through to Nominatim
    }

    // FALLBACK: OSM Nominatim Reverse Geocoding
    final url = Uri.parse(
      'https://nominatim.openstreetmap.org/reverse'
      '?lat=${latLng.latitude}&lon=${latLng.longitude}&format=json'
    );
    final response = await http.get(url, headers: {'User-Agent': 'budolPayApp/1.0'});
    if (response.statusCode == 200) {
      final data = json.decode(response.body);
      if (data != null && data['display_name'] != null) {
        _searchController.text = data['display_name'];
      }
    }
  } catch (e) {
    debugPrint('Reverse geocode error: $e');
  }
}

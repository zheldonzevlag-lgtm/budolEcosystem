📱 budolPay v1.3.93 — Release Documentation

Released: April 17, 2026  |  Build: 1.3.93+194  |  Branch: release/1.3.93

🌍 Release Theme: Web-Safe Geocoding Fallbacks

This release resolves a critical regression where address search and map pin geocoding failed on Flutter Web and emulator environments due to Android/iOS native geocoding service unavailability. A robust OpenStreetMap Nominatim fallback layer has been integrated as a secondary resolver, ensuring reliable address lookup across all platforms.

Executive Summary

The v1.3.93 patch resolves two related issues surfaced during the Address Pinning (KYC flow) feature validation on the Flutter Web development build at 192.168.1.2:9000:

  • Issue 1 — Address search showed "Address not found": The Flutter geocoding package relies on Android/iOS native Google Play Services. On Web, these hooks are absent, causing all forward geocoding (text → coordinates) calls to silently fail.
  • Issue 2 — Pin drop did not auto-fill the address input: Reverse geocoding (coordinates → text) similarly failed on Web, so tapping the map produced no text in the search bar.
  • Fix Applied: Implemented a dual-layer fallback using OSM Nominatim REST API in both MapPicker widget and KYCVerificationScreen. Native geocoding is tried first; on failure, the Nominatim API is called automatically.

Architecture Notes

Dual-Layer Geocoding Strategy

The fallback architecture follows a Try → Catch → Fallback pattern:

  1. Primary (Native OS): placemarkFromCoordinates() / locationFromAddress() via the geocoding Flutter package. Works on physical Android/iOS devices with Google Play Services.
  2. Secondary (OSM Nominatim REST API): https://nominatim.openstreetmap.org — Called automatically when the native method throws any exception. Returns display_name for reverse geocoding and lat/lon for forward geocoding.

This ensures that users testing on Flutter Web, Android emulators without Play Services, or CI environments receive a fully functional address resolution experience.

Compliance

NPC (Data Privacy)

OSM Nominatim queries include only coordinates or address text — no personal identifiers. User identity is not transmitted to external services.

BSP (Bangko Sentral)

Address capture directly supports KYC (Know Your Customer) compliance requirements for present address verification in digital financial services.

Next Steps

  • Consider implementing a typed search suggestions dropdown powered by Nominatim for enhanced UX.
  • Monitor Nominatim usage — it is a free service with rate limiting. Consider upgrading to a paid geocoding provider (e.g., Geoapify) for production at scale.

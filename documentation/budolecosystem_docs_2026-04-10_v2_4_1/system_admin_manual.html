Admin Operations: Anomaly Resolution

Operational Handbook for Institutional Forensic Overrides

Understanding the 'FLAGGED_REVIEW' State

When the Behavioral AI Engine detects a transaction that exceeds institutional deviation thresholds (Z-Score > 3.0), the transaction is automatically placed in a FLAGGED_REVIEW state. No funds are moved until an administrator provides manual clearance.

Institutional Requirement: FLAGGED_REVIEW transactions must be resolved within 4 working hours as per BSP Standard Service levels.

Manual Resolution Workflow

1
Identify Anomaly: View the "Compliance Alerts" section in the Admin Dashboard. Identify transactions with high Risk Scores (90+).
2
Perform Forensic Audit: Expand the transaction details to view riskMetadata. Check the baseline amounts against the current transfer value.
3
Execute Decision: Use the APPROVE or REJECT action on the command panel. You MUST provide a "Reason for Resolution" for BIR/BSP audit trails.

Handling AI False Positives

Sudden valid spikes (e.g., salary bonuses, property purchases) may trigger the AI Shield. Admins should verify the user's KYC tier. Semi-verified or Basic accounts have stricter thresholds than Fully Verified Institutional accounts.

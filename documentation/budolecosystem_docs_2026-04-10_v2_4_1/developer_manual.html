Developer Manual: Anomaly Detection Recovery

Version 2.4.1 | Release Date: 2026-04-10

Technical Objective

This release stabilizes the Behavioral Anomaly Detection Engine by resolving schema mismatches and scoping errors that prevented real-time risk scoring during high-velocity transaction flows.

Data Model Extensions

The Transaction model has been extended to support institutional forensic tracking. These fields are essential for Phase 4 compliance reporting.

model Transaction {
  // ... existing fields
  riskScore    Float?      // 0-100 Behavioral Anomaly Score
  riskMetadata Json?       // Forensic traces (baseline, deviation, method)
  status       TransactionStatus @default(PENDING)
}

enum TransactionStatus {
  PENDING
  COMPLETED
  FAILED
  CANCELLED
  FLAGGED_REVIEW // New status for AI-Shield holds
}

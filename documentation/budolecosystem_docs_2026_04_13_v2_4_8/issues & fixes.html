Issues & Fixes (v2.4.8)

1. NoSuchMethodError: 'toDouble' on String (Mobile)

Issue: Application crashes when user tries to "Cash In" because user['monthlyReceived'] was returned as a String from the backend.

Fix: Implemented AmountUtils.toDouble() to handle heterogeneous types safely.

2. Unresponsive "Verify Challenge" Button (Admin Dashboard)

Issue: Hydration errors caused the Captcha component to fail logic checks or state updates on the client side. Emitted values did not match internal state.

Fix: Moved initialization to useEffect to ensure zero-mismatch between SSR and CSR.

3. Duplicate Forensic Audit Entries

Issue: P2P transfers logged two identical P2P_TRANSFER_COMPLETED events in the audit trail.

Fix: Consolidated all transfer logging into a single handler call in transaction-service.

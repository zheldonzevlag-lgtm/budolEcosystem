System Admin Manual (v2.4.8)

Forensic Audit Management

Admins can now rely on a clean Forensic Audit trail for P2P transfers. Duplicate entries have been eliminated from the database level.

Audit Log Verification

To verify the integrity of recent financial logs, run the following command from the project root:

node scripts/test_scripts/list_recent_logs.js

Admin Dashboard Security

The login captcha flow has been stabilized. If a user reports that the "Verify Challenge" button is unresponsive, ensure they are not using an extremely outdated browser that lacks Support for modern JavaScript Promises.

Security Warning: CAPTCHA challenges now auto-regenerate after 1.5 seconds upon a failed attempt to prevent brute-force automated solvers.

Mobile Service Monitoring

Admins should monitor the Transaction Service logs for any "Failed to parse balance" errors. The v2.4.8 mobile update handles most variations, but systemic backend changes should be coordinated with the Mobile team.

Mitigation Strategies (v2.4.8)

Safe Numeric Parsing (Mobile)

Mitigation: Introduced AmountUtils.toDouble(). This utility acts as a wrapper for all JSON number extraction, providing a default value of 0.0 and handling string/null cases gracefully.

Centralized Audit Middleware (Backend)

Mitigation: Removed manual logging calls from feature handlers. All audit events now flow through a single createAuditLog helper, preventing event duplication and race conditions in logging.

Client-Side Captcha Generation (Admin)

Mitigation: Shifted non-deterministic logic (Math.random) to useEffect. This eliminates hydration mismatches and ensures the captcha is only generated when the client is ready for interaction.

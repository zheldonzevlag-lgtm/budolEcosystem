System Admin Manual: Monitoring Tiered Limits

Admin Overwatch

Admin users can monitor compliance alerts triggered by BASIC users attempting to hit their monthly ceilings. All limit-related rejections are logged as COMPLIANCE_FLAG_TRIGGERED in the Audit Logs.

Limit Parameters (BASIC Tier)

Metric Value Action on Breach
Max Wallet Balance ₱10,000 Hard Block (Error 500)
Monthly Cumulative Inbound ₱5,000 Hard Block (Error 500)
Monthly Cumulative Outbound ₱5,000 Hard Block (Error 500)

Resolution Workflow

If a user complains about being "blocked" while having funds:

  1. Check the user's KYCTier in the Admin Dashboard.
  2. Verify their Monthly Cumulative Volume via the Compliance Board.
  3. If the monthly limit is reached, advise the user to complete Full Verification (KYC) to upgrade to FULLY_VERIFIED status.

Note: Limits for FULLY_VERIFIED users remain at PHP 1,000,000 per day as per BSP Circular 808.

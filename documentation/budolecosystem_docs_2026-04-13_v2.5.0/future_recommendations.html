Future Enhancements & Recommendations

Target: v2.6.0 roadmap Priority: Strategic

1. Native Dark Mode Support

While v2.5.0 focuses on the Ruby & Cream (Light) foundation, we recommend implementing a "Ruby Dark" theme for v2.6.0. This would utilize a Deep Slate/Ruby palette to support user preferences and battery saving on OLED devices.

2. Dynamic Icon Theming

Transition secondary iconography from static PNGs to dynamic SVG paths themed via BrandColors. This will reduce asset size and ensure that even minor icons perfectly match color updates in real-time.

3. Multi-Language (L10n) Branding

Adapt branding typography for regional Philippine dialects. Certain font weights in the "Ruby" palette should be adjusted for Tagalog and Cebuano characters to maintain visual balance.

4. Haptic Feedback Integration

Synchronize haptic patterns with "Ruby" interactions. For example, a "Ruby Pulse" haptic effect during successful QR scans to reinforce the premium brand identity through physical touch.

System Admin Manual: Brand Configuration

System: BudolPay v2.5.0 Component: Mobile Identity

Brand Asset Management

Admin is responsible for ensuring that all promotional assets (Marketing Ads) and Merchant icons uploaded via the Admin Dashboard align with the Ruby & Cream palette.

  • Primary Color: #BC1C44 (Ruby)
  • Foundation Color: #FFF0E5 (Cream)

Marketing Ads Configuration

When uploading new banners via the Backend API / Admin UI:

  1. Use high-resolution PNG or SVG assets.
  2. Ensure a 16:9 aspect ratio for home screen carousels.
  3. Favor Ruby/Cream gradients over the legacy Rose/White gradients to prevent visual jarring.

Troubleshooting Visual Glitches

If a screen appears with the legacy "Rose Pink" color:

  • Verify the BrandColors implementation in the mobile source.
  • Clear the application cache on the user device to force a rebuild of dynamic assets.
  • Ensure the local shared_preferences for "Theme" (if applicable) is not overriding system defaults.

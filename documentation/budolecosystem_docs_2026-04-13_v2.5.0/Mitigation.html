Mitigation Strategies - v2.5.0

M-250-1: Backward Compatibility Layer

Risk: R-250-3 (Legacy build failures)

Strategy: Restored background and surface getters in BrandColors to point to lightBackground/lightSurface respectively. This prevents compilation errors in older modules while allowing phased migration.

M-250-2: Scroll-Safe Design

Risk: R-250-1 (UI Overflow)

Strategy: Wrapped the Home Screen in SingleChildScrollView with AlwaysScrollableScrollPhysics. This ensures that even if a Vertical layout is chosen on small devices, the content remains accessible via scrolling.

M-250-3: Strict Progress Logic

Risk: R-250-2 (Inaccurate Completion)

Strategy: Decoupled progress calculation from the UI layer. Logic resides in api_service.dart and uses strictly Boolean checks on non-null nullable fields, ensuring consistent state across all consumers.

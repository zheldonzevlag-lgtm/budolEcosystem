Developer Manual: Brand Identity Refresh

Tech Stack: Flutter, Dart Version: v2.5.0

Design System Integration

The core of this release is the BrandColors class. Developers MUST utilize this class for all UI components to ensure systemic consistency.

Code Reference: BrandColors Utility

Path: lib/utils/brand_colors.dart

class BrandColors {
  static const Color primary = Color(0xFFBC1C44);     // Deep Ruby
  static const Color background = Color(0xFFFFF0E5);  // Cream Foundation
  static const Color textPrimary = Color(0xFF1E293B); // Dark Slate
  // ...
}

Screen Implementation Notes

Below are key screens migrated to the Ruby & Cream system. Implementation details focus on the transition from the legacy Rose theme to the new premium palette.

1. Splash & Auth Foundation

  • File: splash_screen.dart
  • Change: Transformed background from Dark Indigo to Cream, updating the logo transition to Ruby.

2. Financial Transaction UI

  • File: add_money_screen.dart
  • Change: Updated all primary action buttons and input highlights to BrandColors.primary.
  • File: qr_scanner_screen.dart
  • Change: Refactored CustomPainter logic to use Ruby guides and scanning laser.

3. Identity Verification (KYC)

  • File: kyc_verification_screen.dart
  • Change: Migrated the multi-step progress indicator and all verification tooltips to the Ruby palette.

Best Practices

  1. Never use hardcoded hex: Use BrandColors.primary instead of Color(0xFFBC1C44).
  2. Backgrounds: Always wrap main screen content in a Scaffold with backgroundColor: BrandColors.background.
  3. Typography: Use BrandColors.textPrimary for standard reading and BrandColors.primary for emphasized call-to-actions.

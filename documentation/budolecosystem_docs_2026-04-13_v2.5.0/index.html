Version 2.5.0: Ruby & Cream Brand Identity Refresh

Released: April 13, 2026 Status: COMPLIANT Module: BudolPay Mobile

Purpose & Rationale

This release executes the systemic brand identity migration of the BudolPay mobile application to the "Ruby & Cream" design system. This transformation replaces the legacy "Rose Pink" palette with a premium, high-contrast visual language designed to enhance user trust and emotional resonance.

Rationale: Align with international fintech aesthetics (premium tier) while maintaining local accessibility compliance (BSP and NPC guidelines).

Technical Explanation

The migration utilized a centralized BrandColors utility class to eliminate hardcoded hex values across the mobile module. Key technical shifts include:

  • Foundation Shift: Transition from Cold White to Warm Cream (#FFF0E5) to reduce eye strain and improve accessibility.
  • Brand Accentuation: Adoption of Deep Ruby (#BC1C44) for all primary interaction points.
  • Systemic Refactoring: Total overhaul of over 15 screens including Splash, KYC, Payments, and Settings.

Compliance Verification

All UI changes have been vetted for color contrast accessibility under WCAG 2.1 standards, ensuring readability for users with visual impairments. PCI DSS and BSP-mandated security warnings have been maintained and enhanced for visibility.

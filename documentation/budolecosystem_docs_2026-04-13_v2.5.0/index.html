Release v1.3.85: Adaptive UI & Flexibility

COMPLIANT

Purpose & Rationale

The v1.3.85 update focuses on enhancing user engagement and system accessibility through an Adaptive UI framework. Following the "Ruby & Charcoal" design system, this release eliminates legacy hardcoded styling in favor of semantic theme tokens, enabling a seamless transition between Light, Dark, and Auto theme modes.

Key Objectives:

  • Drive user profile completion via the New Profile Completeness widget.
  • Enhance Home Screen personalization with Smart Greeting layout toggles.
  • Purge hardcoded "Slate" hex values across secondary modules (Wallet, Transfer, KYC).
  • Ensure high-contrast visibility for technical compliance (PCI DSS/BSP accessibility standards).

Technical Explanation

The implementation utilizes ColorScheme tokens defined in BrandColors. By wrapping the root MaterialApp in a Consumer that listens to ApiService, the application reacts instantly to theme changes without state loss.

Architecture Highlights:

  • Flexible Layout Engine: The Home Screen now uses Flex-based conditional wrappers to toggle between Vertical and Classic greeting styles.
  • Data-Drive Progress: Profile completeness is calculated dynamically by evaluating mandatory KYC fields, encouraging users to reach 100% for full financial feature unlocks.

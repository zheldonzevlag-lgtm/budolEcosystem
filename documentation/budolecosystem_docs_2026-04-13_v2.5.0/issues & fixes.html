Issues & Post-Implementation Fixes

Release Cycle: v2.5.0 Status: All Issues Resolved

Issue 1: Constant Construction Errors

Description: Several screens (QR Scanner, KYC Verification) failed compilation with const_with_undefined_constructor errors when using BrandColors.primary within const contexts.

Root Cause: BrandColors.primary is a static const member, but using the const keyword before the identifier is incorrect for member access in list literals or assignments.

Fix: Removed the const prefix from the access points and updated chained method calls (e.g., .withAlpha()) to standard runtime evaluations.

Issue 2: Overlapping Text in Marketing Ads

Description: Promotional text on the Marketing Ads screen became unreadable when displayed over the new Cream background due to lingering light-colored shadows.

Root Cause: Legacy shadow logic was optimized for dark-mode backgrounds.

Fix: Implemented BrandColors.textSecondary with subtle dark-grey offsets to ensure legibility on light surfaces.

Issue 3: Incomplete Privacy Masking

Description: User's full name was partially visible during the splash transition.

Fix: Integrated budolID sync earlier in the splash lifecycle to ensure valid masking before the dashboard entry.

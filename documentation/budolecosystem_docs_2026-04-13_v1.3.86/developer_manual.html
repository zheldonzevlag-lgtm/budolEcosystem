Developer Manual: Rose & Cream Theme

Color Logic migration

In v1.3.86, we transitioned from hardcoded text colors to context-aware tokens. Developers MUST use Theme.of(context).colorScheme for all UI elements.

// INCORRECT (Legacy) style: TextStyle(color: BrandColors.textPrimary) // CORRECT (v1.3.86+) style: TextStyle(color: Theme.of(context).colorScheme.onSurface)

Input Decoration

Focused borders have been enhanced for accessibility. The current configuration in BrandColors.dart is:

  • Width: 2.8px
  • Color: Theme Primary
  • Fill: Surface (White in light mode)

Logo Implementation

The logo uses UIUtils.formatBudolPayText(). In Light Mode, the "budol" prefix now inherits onSurface (Deep Ruby) instead of defaulting to black/white.

Code Location Reference

The core z-index adjustment was introduced directly inside the CategorySelector client-side dropdown panel definition.

Source File: CategorySelector.jsx (Lines 222-224)

Technical Explanation of the Change

In AddProductWizard.jsx, the StickyFooter has a fixed layout positioning setting z-index: 50 (Tailwind z-50). The CategorySelector dropdown also defaulted to z-50. Since StickyFooter was rendered later in the DOM tree, it created a new stacking context that stacked above the dropdown panel.

This layout overlap prevented click interactions on elements positioned at the bottom of the scroll viewport, such as the 12th category "Toys, Games & Collectibles". Raising the dropdown z-index to z-[60] causes the browser layout engine to paint the dropdown layer on top of the StickyFooter panel, restoring complete pointer-events registration.

// CategorySelector.jsx - Dropdown Panel
{isOpen && (
- <div className="absolute z-50 w-full mt-2 bg-white border border-slate-200 rounded-2xl shadow-xl overflow-hidden">
+ /* z-[60] ensures dropdown renders above StickyFooter (z-50) so bottom items like "Toys, Games & Collectibles" remain clickable */
+ <div className="absolute z-[60] w-full mt-2 bg-white border border-slate-200 rounded-2xl shadow-xl overflow-hidden">

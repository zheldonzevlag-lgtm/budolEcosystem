Recommendations for Next Releases

  • Unified Overlay Manager: Introduce a centralized React state manager or viewport registry to dynamically compute z-index values, avoiding static layout conflicts between wizard footers, toast notifications, modals, and custom select selectors.
  • Auto-Scroll-into-View: When a user opens a selector, automatically scroll selected items or scroll view containers to center the selection options in the viewport, ensuring maximum accessibility on mobile devices.
  • Automatic Selection Collapse: Once a leaf category is chosen, auto-collapse the selection overlay container to minimize scroll gestures.

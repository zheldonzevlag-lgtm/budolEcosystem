Identified Defect

Issue #1: Pointer-Events Ignored on Category Dropdown Bottom Elements

Description: On `/store/add-product`, the bottom item in the category selector dropdown list ("Toys, Games & Collectibles") could not be selected. When clicked, it would either fail to register or click the "Next" button in the StickyFooter below.

Root Cause: The CategorySelector container layout block used `z-50`. The page layout has a sticky bottom panel container (`StickyFooter`) which also renders with `z-50`. Because StickyFooter renders later in the DOM tree, it stacked above the dropdown. Bottom items in the dropdown overlay area were blocked from receiving pointer-events.

Resolution Applied

Fix #1: Elevate Category Dropdown Stacking Layer

Action Taken: Increased z-index of the CategorySelector dropdown container in `CategorySelector.jsx` to `z-[60]`.

Verification: Re-tested the click interaction. The dropdown overlay renders on top of the StickyFooter panel, and pointer-events register on the bottom-most list options, including "Toys, Games & Collectibles".

Adding a Product – Step-by-Step Instructions

  1. Navigate to Store Setup
    Open the seller portal dashboard and select Add Product.
  2. Click Category Selector
    Click on the Select Category field. The category dropdown overlay will open.
  3. Choose Main Category
    Scroll down to the bottom list element. You can now hover, focus, and click on Toys, Games & Collectibles directly.
  4. Select Subcategories
    Upon selecting the main category, the subcategories list panel will dynamically populate in the secondary column. Select your target subcategories.
  5. Save
    Complete the remaining product fields (Title, Price, Stock, Description) and click Next / Save Product in the StickyFooter.

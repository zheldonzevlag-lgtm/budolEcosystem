Mitigation Control M-UX-01 (z-index Overlaps)

Control Strategy: Raised the dropdown component z-index class from `z-50` to `z-[60]` while keeping the StickyFooter z-index fixed at `z-50`. This establishes a distinct layered stacking order, preventing lower layout nodes from blocking user tap actions.

Mitigation Control M-SEC-01 (Input Validation)

Control Strategy: Category identifier selection inputs are validated via static enum lists in backend models. Attempts to inject invalid inputs trigger standard API validation errors instead of executing database calls, mitigating injection vectors.

Mitigation Control M-COMP-01 (Compliance Controls)

Control Strategy: Audits are executed on database access layers. The frontend adjustment does not touch database layers, preserving compliance posture across all transactional modules.

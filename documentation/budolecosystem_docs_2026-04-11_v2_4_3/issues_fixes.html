Compliance Log: Issues & Resolutions

Phase: 6 (Documentation) Date: 2026-04-11

Issue #1: Database Schema Desync (Enum Mismatch)

Status: FIXED

Problem: The Prisma Schema included MANAGER and GENERAL_MANAGER roles, but the live PostgreSQL database was out of sync, causing ConnectorError: invalid input value for enum during E2E testing.

Resolution:

  1. Performed a manual JSON backup of core tables (Users, Transactions, Wallets) into \backup-db\db-2026-04-11.
  2. Synchronized database schema using npx prisma db push.
  3. Verified enums using forensic check script check_db_roles.js.

Issue #2: Silent Audit Log Failure

Status: FIXED

Problem: Mismatched arguments in the /resolve endpoint were bypass-calling the centralized audit helper with req as the first parameter, resulting in undefined action keys and zero forensic logs generated.

Resolution: Corrected calls in services/transaction-service/index.js to utilize the local createAuditLog helper with the proper institutional metadata mapping.

Issue #3: Transaction Atomicity in Resolution

Status: VERIFIED

Problem: Risk of partial resolution (funds dispersed but status not updated).

Resolution: Implemented sequential service calls and audit logging within the GENERAL_MANAGER authorization block. Future iteration will move these to a database transaction for absolute atomicity.

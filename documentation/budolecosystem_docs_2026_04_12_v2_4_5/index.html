BudolPay v2.4.5: Mobile Geocoding Enhancement

Version: 2.4.5

Date: 2026-04-12

Category: Mobile Application / Frontend

Purpose

The primary objective of this release is to improve the user experience during account verification by replacing raw geographic coordinates with human-readable addresses in the "Present Address" field.

Rationale

Displaying raw longitude and latitude (e.g., 14.59, 120.98) is unintuitive for users and prone to data entry errors. Following market standards, addresses must be presented in a textual format that users can easily recognize and verify.

Scope

  • Integrated geocoding and connectivity_plus libraries in BudolPay Mobile.
  • Implemented Reverse Geocoding in the KYC Verification flow.
  • Added connectivity safeguards to ensure address resolution success.

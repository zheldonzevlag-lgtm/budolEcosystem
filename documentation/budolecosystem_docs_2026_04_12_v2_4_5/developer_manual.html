Developer Manual: Mobile Geocoding Integration

Technical Overview

This update integrates native geocoding capabilities into the Flutter mobile application to resolve human-readable addresses from geographic coordinates.

Dependencies

dependencies:
  geocoding: ^3.0.0
  connectivity_plus: ^6.1.0

Implementation Details

Address Resolution Logic

Located in: kyc_verification_screen.dart

The _pinAddress function follows a 3-phase execution model:

  1. Connectivity Check: Uses Connectivity().checkConnectivity() to ensure API access.
  2. Coordinate Retrieval: Launches MapPicker widget.
  3. Reverse Geocoding: Calls placemarkFromCoordinates() and parses the result into a full detail string.

Code Reference

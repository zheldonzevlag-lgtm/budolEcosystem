Executive Summary

This audit identified 34 security vulnerabilities across the budolEcosystem codebase. The most dangerous findings involve completely unauthenticated financial endpoints (wallet balance modification, payment processing), hardcoded secrets committed to source control, and authentication bypass mechanisms that allow any attacker to gain admin privileges.

CRITICAL VULN-01 Hardcoded JWT Secret with Predictable Fallback ▼

Files

budolID-0.1.0/index.js:94 budolpay-0.1.0/services/auth-service/index.js:164 budolpay-0.1.0/services/api-gateway/index.js:130

Risk

If JWT_SECRET env var is unset in production, the hardcoded fallback is used. An attacker with source code access can forge any JWT token and impersonate any user including admins, gaining full access to financial operations.

Attack Vector

Attacker reads source code, uses the known secret to sign a JWT with role: 'ADMIN', and submits it to any authenticated endpoint.

Security Hardening Action Plan

P1
CRITICAL — Immediate
Days 1-3 | Must complete first
Impact: Requires updating all .env files across the ecosystem and rotating all exposed secrets. Expect 2-4 hours of downtime for secret rotation.

1.1 Remove All Hardcoded Secrets (VULN-01, 06, 07, 18, 19, 20, 21)

Remove ALL hardcoded fallback values. Require env vars — crash on startup if missing. Rotate ALL exposed secrets.

// BEFORE (insecure)
const JWT_SECRET = process.env.JWT_SECRET || 'GJ7Lxn0/kdV/KuZJ5xJ7Ip0RvMerrGW5n0gf44mfHgc=';

// AFTER (secure)
if (!process.env.JWT_SECRET) {
    console.error('FATAL: JWT_SECRET environment variable is required');
    process.exit(1);
}
const JWT_SECRET = process.env.JWT_SECRET;
Files: budolID-0.1.0/index.js auth-service/index.js api-gateway/index.js upload_logo_to_cloudinary.js seed_user.js create_admin.js
Verify: grep -r "|| '" --include="*.js" should return no hardcoded secrets. App crashes if JWT_SECRET not set.

1.2 Fix Wallet Service Auth Bypass (VULN-03, 04, 31)

Remove x-bypass-auth header bypass. Remove /update-balance and /process-qr from unauthenticated list.

// BEFORE (insecure)
app.use((req, res, next) => {
    if (req.path.endsWith('/health') || 
        req.path.endsWith('/update-balance') || 
        req.path.endsWith('/process-qr') ||
        req.headers['x-bypass-auth'] === 'true'
    ) {
        if (!req.user) req.user = { userId: 'test-user-id', role: 'ADMIN' };
        return next();
    }
    verifyToken(req, res, next);
});

// AFTER (secure)
app.use((req, res, next) => {
    if (req.path.endsWith('/health')) return next();
    verifyToken(req, res, next);
});
Verify: curl with x-bypass-auth header returns 401. Unauthenticated requests to /update-balance return 401.

1.3 Fix API Gateway Auth Bypass (VULN-02, 08)

Remove development mode bypass entirely. Reject invalid tokens instead of forwarding.

// BEFORE (insecure)
const verifyToken = (req, res, next) => {
    if (process.env.NODE_ENV === 'development') {
        return next(); // ALL REQUESTS PASS
    }
};
// ...
} catch (err) { next(); } // forwards invalid tokens

// AFTER (secure)
const verifyToken = (req, res, next) => {
    const token = req.headers['authorization']?.split(' ')[1];
    if (!token) return res.status(401).json({ error: 'Access token required' });
    try {
        req.user = jwt.verify(token, JWT_SECRET);
        next();
    } catch (err) {
        return res.status(401).json({ error: 'Invalid or expired token' });
    }
};

1.4 Fix Transaction Service Auth (VULN-09)

Uncomment the verifyToken middleware.

// BEFORE
// app.use(verifyToken);

// AFTER
app.use(verifyToken);

1.5 Fix CORS Configuration (VULN-05)

Replace wildcard CORS with explicit allowed origins.

// BEFORE (insecure)
app.use(cors({ origin: '*', credentials: true }));

// AFTER (secure)
const ALLOWED_ORIGINS = [
    process.env.NEXT_PUBLIC_APP_URL,
    process.env.NEXT_PUBLIC_BASE_URL,
    'http://localhost:3000',
].filter(Boolean);

app.use(cors({
    origin: (origin, callback) => {
        if (!origin || ALLOWED_ORIGINS.includes(origin)) callback(null, true);
        else callback(new Error('Not allowed by CORS'));
    },
    credentials: true,
}));

Apply same fix to websocket-server/server.js.

2.1 Add Rate Limiting (VULN-14, 15)

Install express-rate-limit and apply to all sensitive endpoints.

npm install express-rate-limit

const rateLimit = require('express-rate-limit');

const loginLimiter = rateLimit({
    windowMs: 15 * 60 * 1000, max: 5,
    message: { error: 'Too many login attempts' }
});

const otpLimiter = rateLimit({
    windowMs: 5 * 60 * 1000, max: 3,
    message: { error: 'Too many OTP attempts' }
});

const financialLimiter = rateLimit({
    windowMs: 60 * 1000, max: 10,
    keyGenerator: (req) => req.user?.userId || req.ip
});

app.post('/auth/sso/login', loginLimiter, loginHandler);
app.post('/verify-otp', otpLimiter, otpHandler);
app.post('/update-balance', financialLimiter, updateBalanceHandler);

2.2 Add WebSocket Authentication (VULN-10, 11)

Require JWT for WebSocket connections and protect /trigger endpoint.

io.use((socket, next) => {
    const token = socket.handshake.auth.token;
    if (!token) return next(new Error('Authentication required'));
    try {
        socket.user = jwt.verify(token, JWT_SECRET);
        next();
    } catch (err) { next(new Error('Invalid token')); }
});

io.on('connection', (socket) => {
    socket.on('subscribe', (channelName) => {
        if (channelName === `user:${socket.user.userId}` || 
            socket.user.role === 'ADMIN') {
            socket.join(channelName);
        }
    });
});

2.4 Fix XSS Vulnerabilities (VULN-13, 16)

HTML-escape all user input. Remove password from error redirect.

function escapeHtml(str) {
    if (!str) return '';
    return String(str).replace(/&/g,'&').replace(//g,'>').replace(/"/g,'"');
}

// Use for all interpolated values:
value="${escapeHtml(activeApiKey)}"

// Remove password from redirect:
return res.redirect(`/login?...&email=${encodeURIComponent(email)}`);
// Never pass password in URL

2.5 Add Security Headers (VULN-27)

Add helmet to all Express services.

npm install helmet

const helmet = require('helmet');
app.use(helmet({
    contentSecurityPolicy: {
        directives: {
            defaultSrc: ["'self'"],
            scriptSrc: ["'self'"],
            styleSrc: ["'self'", "'unsafe-inline'"],
            imgSrc: ["'self'", "data:", "https://res.cloudinary.com"]

    hsts: { maxAge: 31536000, includeSubDomains: true }

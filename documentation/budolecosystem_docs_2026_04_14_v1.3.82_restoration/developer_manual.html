v1.3.82 Heritage Baseline Manual

Architecture Summary

This codebase is pinned to the v1.3.82 Institutional Baseline. Developers must not introduce adaptive theming logic or third-party gradient packages (e.g., mesh_gradient) without explicit authorization.

Branding Standard

  • Primary Heritage Color: #F43F5E (Rose 500)
  • Secondary/Background Color: #0F172A (Slate 900)
  • UI Logic: Hardcoded within screens or derived from the static Material 3 seed in main.dart.

Key Files

  • main.dart - Entry point with static ThemeData.
  • api_service.dart - Stripped of theme-state logic.
  • login_screen.dart - Solid original background implementation.

Critical Restriction

Do not re-introduce the budolPayMobile/lib/utils/brand_colors.dart file. This file was discarded to ensure consistency with the user-requested v1.3.82 standard.

Description of Critical Risks

FIN-001: Money Laundering (Lower than Threshold)

Users may intentionally split large transactions into multiple amounts just below the PHP 500,000 threshold. While the Aggregate limit (1M) catches some, sophisticated actors can distribute this across multiple days.

SEC-001: Bypass via Multiple Distributed Accounts

Account-centric monitoring may fail if a single entity controls multiple accounts with differing KYC identities (Money Mules). This requires future AI-based identity graphing.

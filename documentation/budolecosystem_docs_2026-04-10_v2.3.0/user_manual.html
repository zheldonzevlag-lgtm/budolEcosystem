User Manual: Compliance Monitoring Dashboard

Version: 2.3.0 | Target Audience: Compliance Officers, Risk Managers

Introduction

The Compliance Monitoring Dashboard is your primary tool for enforcing financial integrity within the BudolPay ecosystem. It automates the detection of suspicious patterns, allowing you to focus on high-priority forensic reviews.

Key Responsibility

Compliance Officers are responsible for reviewing every HIGH RISK flag within 4 business hours to ensure adherence to Anti-Money Laundering (AML) regulations.

interpreting the Monitoring Board

The board displays real-time alerts. Here is how to read them:

  • Rule: HVT (High-Value Transaction) - Triggered when a single transaction is ≥ PHP 500,000. Check the source of funds.
  • Rule: VELOCITY - Triggered by high-frequency transfers. May indicate automated "layering" or fraud.
  • Rule: DAILY_AGGREGATE - Triggered when a user's total daily volume hits institutional limits. Review for undeclared business activity.

Performing a Forensic Review

  1. Locate the flagged transaction on the Compliance Board.
  2. Note the Reference ID and User KYC Tier.
  3. Click "Review Transaction" to view the full ledger entry and participant history.
  4. If the activity is deemed suspicious, initiate a Suspicious Activity Report (SAR) via the institutional regulatory portal.

Institutional Standards

All monitorings adhere to the Data Privacy Act (NPC). Patient details and transaction metadata are only visible to authorized Compliance staff identifiers.

Mitigation Plan (v2.4.9)

M-249-01: Eye-con Masking (Default: Hidden)

To prevent shoulder-surfing and unauthorized name exposure, the user greeting is masked by default with bullet characters (•). Persistent state for visibility is NOT used to ensure privacy on every app restart.

M-249-02: Universal Fallback Masking

In cases where legal names are not yet configured, the system falls back to the masked email (NPC compliant masking logic) instead of the plain-text email identifier.

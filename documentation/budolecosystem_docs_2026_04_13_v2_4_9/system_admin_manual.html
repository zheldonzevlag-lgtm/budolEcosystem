System Admin Manual (v2.4.9)

1. Data Governance

Admins should ensure that users are encouraged to fill in their First and Last names to improve the quality of financial audit trails. System-generated identifiers (emails) are now secondary to legal names in the UI.

2. Audit Logs

All profile name changes are logged in the Security audit trail. Admins can verify these changes by searching for the PROFILE_UPDATE action in the forensic audit dashboard.

Important: In compliance with BSP Circular 808, name changes for FULLY_VERIFIED accounts are restricted and must be handled manually by a General Manager after checker approval.

3. Monitoring

Monitor the auth-service logs for any Universal Sync errors, as these may indicate name data mismatches between budolID (SSO) and budolPay local storage.

Future Recommendations (v2.5.0+)

1. Mandatory Name Capture for Email Logins

Currently, email-only users may have empty name fields. It is recommended to implement a mandatory "Profile Setup" screen immediately after email registration to ensure the UI can always display a legal name.

2. Biometric-Linked Name Display

Allow the UI to unlock the name display automatically upon successful biometric authentication (Face/Fingerprint) instead of requiring manual toggle, for a more seamless "Private by Choice" experience.

3. Nickname/Display Name Support

In addition to legal names, allow users to set a preferred "Nickname" for the Home Screen greeting, while keeping the full legal name for the Settings and KYC screens.

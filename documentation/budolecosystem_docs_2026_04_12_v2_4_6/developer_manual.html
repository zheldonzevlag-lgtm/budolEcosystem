Developer Manual: Release v2.4.6 & Dashboard UI

Technical Overview

This update compiles the Mobile App APK Release (v1.3.82) containing Reverse Geocoding support, and fixes uncommitted layout issues in the Admin Web Dashboard involving the CSS Grid presentation of layout cards.

Dependencies & Compilation

The Flutter application was built using the flutter build apk --release targeting the latest Android build architecture with optimized Tree-shaken icons to drastically strip unused assets (99.2% reduction on icons). The resulting built application (app-release.apk) was transferred and versioned into the standard android installer directory.

Implementation Details

Admin Dashboard Layout Re-structure

Located in: budolpay-0.1.0/apps/admin/app/page.tsx

The layout for ComplianceBoard.tsx components previously presented responsiveness issues on medium screens. The grid logic was updated to grid-cols-2 md:grid-cols-3 to handle specific screen breakpoints properly and the compliance shield icon was re-scaled for aesthetics.

BudolPay v2.4.6: Admin Dashboard UI Fix & Mobile APK Build Release

Version: 2.4.6

Mobile Version: 1.3.82+183

Date: 2026-04-12

Category: Release / Frontend UI Dashboard

Purpose

The primary objective of this release is to compile the Mobile App APK Release (v1.3.82) containing Reverse Geocoding support, and fix uncommitted layout issues in the Admin Web Dashboard.

Rationale

In the previous sessions, optimizations to the Admin dashboard and Mobile app dependencies were formulated but not completely committed or packaged and needed a wrap up. We ran the test suite, built the mobile release, and packaged the APK.

Scope

  • Compiled and completed Flutter Mobile application release `v1.3.82` (1.3.82+183).
  • Transferred the released artifact to `\android-installer\budolPay 1.3.82.apk`.
  • Fixed Admin dashboard layout component grids.
  • Corrected hardcoded missing directory issues causing failed tests in `infrastructure-audit.test.js`.

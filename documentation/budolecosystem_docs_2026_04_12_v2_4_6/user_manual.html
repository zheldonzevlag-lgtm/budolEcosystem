User Manual: How to Pin Your Address

During account verification, you will see a "Present Address" field with a "Pin" button.

  1. Tap the Pin button.
  2. Find your location on the map and tap "Select Location".
  3. The app will automatically resolve your full address (e.g., Street, City, ZIP).
  4. Note: You must have an active internet connection for the address to appear.

System Admin Manual: Geocoding Management

Geocoding relies on the device's native OS services. No additional server-side configuration is required for v2.4.5.

  • API Keys: Uses native Android (Google Play Services) or iOS (Apple Maps) credentials configured in the build flavor.
  • Debugging: If addresses fail to resolve, check the device's location permissions and internet connectivity.

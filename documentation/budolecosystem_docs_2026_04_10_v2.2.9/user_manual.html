User Manual

Version: 2.2.9 | Date: 2026-04-10

Overview

BudolPay ecosystem interfaces have been updated for stability and ease of use.

1. Mobile Login flow

Mobile users will now reliably connect via OTP instead of encountering a broken page upon authentication fallback. Simply request your OTP, enter it into the mobile interface securely, and you will be directed into the BudolPay ecosystem smoothly.

2. Admin Access via BudolID

Staff members accessing the Admin Portal will now be met with more resilient feedback toasts if incorrect details are entered. Your form fields will not be cleared, allowing you to quickly spot typos in your email instead of starting over. A popup at the top of the interface will describe the exact reason for the failure.

System Admin Manual

Version: 2.2.9 | Date: 2026-04-10

Overview

This update adds specific UX handling to the admin web console and tightens forensic log tracing. As a System Administrator, you will now see Staff Identity displaying full names in the Security Audit view, giving stronger accountability across BSP/PCI-DSS checks.

1. Database Sync

The Prisma `User` schema in the `admin` app has been synced with the Core Ecosystem to include OTP authentication columns (`otpCode`, `otpExpiresAt`, `otpUpdatedAt`). The primary administration node must run npx prisma generate any time cross-app dependencies shift to ensure accurate mapping.

2. Audit Trail Visibility

You can access the System Compliance page under "Security & Audit". A new "Staff Identity" label displays alongside the "Entity Details" metadata. This pulls from denormalized trace metadata generated automatically by standard SSO authentication flow handlers.

3. Troubleshooting Client Connections

If mobile apps fail OTP validation over 500 errors, first check if the central auth API is reachable at /login/mobile/verify-otp or /verify-otp, as both are now officially supported internally via Node.js routing.

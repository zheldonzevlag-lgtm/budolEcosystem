Resolved Issues Log

ID Subsystem Issue Description Root Cause Fix Applied
ISS-229-01 Auth API Mobile app received HTML error page on OTP submission. The mobile App hit /login/mobile/verify-otp, but Express only routed /verify-otp. An unhandled 404 fell back to the root HTML response. Bound ['/verify-otp', '/login/mobile/verify-otp'] to the same POST handler.
ISS-229-02 Admin Security UI "System" or missing identities in the Forensic Audit Logs during user logouts. Database schema missing OTP fields in the Admin local schema, and missing related User objects when dealing with external auth identities (via SSO), causing fallback logic to drop names. Modified lib/audit.ts to denormalize actorName and actorEmail into metadata JSON, and updated the frontend to parse these securely.
ISS-229-03 Admin Login UX Error strings during failed logins cleared user credentials instead of preserving them. State overwrite logic inherently reset input variables on catch. Implemented react-hot-toast to display stackable non-intrusive alert popups.

System Admin Manual v2.2.7

Monitoring Forensic Accountability

System Administrators can verify forensic integrity by navigating to Security & Audit > Forensic Audit Trail. Every administrative action must now display a verified Actor Email and Full Name.

Compliance Check: If an event appears with "Actor: SYSTEM" for a non-automated task (e.g., account provision), immediately check the adminId transmission in the offending API.

Log Exporting for Regulatory Audit

To export logs for BSP or NPC audits, use the Download Full Trail (JSON) feature. The exported payload now includes the denormalized actorName and actorEmail fields, ensuring individual accountability regardless of local database record changes.

Historical Issues & Institutional Fixes v2.4.0

Documenting technical challenges encountered during the implementation of the Behavioral Scoring Engine.

Parsing Failure: TypeScript Syntax in JavaScript FIXED

Behavior: Internal Jest tests failed to parse index.js during logic verification.

Root Cause: Erroneous use of as object casting syntax (TypeScript) within the /resolve route handler in a CommonJS JavaScript file.

Fix: Reverted to native JavaScript object spread syntax: { ...tx.riskMetadata }.

Cold Start Boundary Logic Inaccuracy FIXED

Behavior: One test case for Cold Start Median Fallback failed at exactly the 50-point threshold.

Root Cause: Comparison was using strictly greater than toBeGreaterThan(50) when the mathematical result for exactly 6x median was exactly 50.

Fix: Updated verification suite to toBeGreaterThanOrEqual(50) and refined the EWMA smoothing loop to handle floating point precision in history arrays.

Logic Coupling in Transaction Root REFACTORED

Behavior: Testing the AI logic required booting the entire Express app and Database, leading to fragile tests.

Fix: Extracted core calculation math into riskEngine.js, allowing for pure, dependency-free unit testing of the EWMA algorithm.

Syntax Error: Admin UI Build Failure FIXED

Behavior: Admin dashboard failed to compile during v2.4.0 deployment due to an Expression expected error.

Root Cause: Premature closing brace }; in the ComplianceAlert interface of ComplianceBoard.tsx.

Fix: Repaired the interface structure and corrected TypeScript property alignments to restore dashboard stability.

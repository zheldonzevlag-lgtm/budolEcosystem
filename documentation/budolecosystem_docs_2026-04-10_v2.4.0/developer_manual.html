This manual documents the integration of the Behavioral Baselining Engine (BBE) into the BudolPay transaction flow. The engine leverages smoothing algorithms to detect institutional risk in real-time.

1. Core Algorithm: EWMA

The system uses an Exponentially Weighted Moving Average (EWMA) with a smoothing factor α = 0.2. This allows the system to prioritize recent behavior while maintaining a long-term memory of user habits.

Baselinet = (α * Amountt) + ((1 - α) * Baselinet-1)

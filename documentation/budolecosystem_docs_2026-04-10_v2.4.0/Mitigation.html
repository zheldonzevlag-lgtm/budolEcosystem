Behavioral Risk Mitigation Strategy v2.4.0

Detailed explanation of the security mechanisms deployed to neutralize behavioral threats.

PREVENTATIVE
1. Dynamic Baselining (EWMA)

Instead of rigid transaction limits (e.g., PHP 50,000), the system mitigates fraud by learning the individual habit of each user. A user who typically transacts PHP 1,000 will be mitigated at PHP 5,000, while a high-net-worth user will be allowed greater flexibility based on their authenticated history.

DETECTIVE
2. Cold Start Protection Median

To mitigate the risk of "Sleeper Accounts" (new accounts activated for one large fraud), the system uses a PHP 2,500 Global Median as the starting baseline. Any transaction significantly exceeding this median before a behavioral pattern is established is automatically escalated for manual review.

CORRECTIVE
3. Institutional Override / Manual Clearance

The system provides a clear corrective path. Compliance officers can review Risk Metadata to distinguish between legitimate life events (e.g., a one-time tuition payment) and illicit activity (e.g., rapid wallet draining), ensuring minimal friction for valid transactions.

AUDITABLE
4. Artifact-Backed Legality

Every risk decision (AI-score) and every admin resolution (Approve/Reject) is backed by a permanent audit log, satisfying BSP requirements for transactional transparency and accountability.

Risk Register (v2.4.7)

Risk ID Description Impact Severity Mitigation Strategy
RSK-MAP-001 Inaccurate coordinate resolution (GPS Drift) Compliance High Manual verification required for addresses with low confidence scores. PIN remains ground truth.
RSK-MAP-002 Geocoding API Rate Limiting / Cost Spikes Operational Medium Implemented search throttling and ensured only final "submit" coordinates are definitively resolved.
RSK-MAP-003 Ambiguous Search Results Accuracy Low The PIN remains the ground truth; textual search only moves the map, requiring user confirmation of the visual PIN placement.

Release Issues & Fixes: v2.4.7

Status: All RESOLVED Date: 2026-04-12

Critical Blockers Resolved

Issue: Test Suite Hangs Indefinitely

Symptoms: npm test would never finish after transaction-service tests began.

Root Cause: Added setInterval for DRS Heartbeat was preventing the Node process from exiting.

Fix: Applied .unref() to the interval timer.

Issue: SyntaxError for ESM Imports

Symptoms: realtime.test.js failed with Cannot use import statement outside a module.

Root Cause: Jest environment in budolpay-0.1.0 is CommonJS, while workspace dependency budolshap-0.1.0 is ESM.

Fix: Inlined the specific triggerRealtimeEvent logic into the test file to eliminate external dependency pathing errors during audit.

Issue: Database Missing Error in verify_admin_role

Symptoms: Test failed looking for budolpay_db.

Root Cause: Stale test code referencing legacy database naming conventions.

Fix: Consolidated verification to only check the production-standard budolpay database.

Issue Resolution

Unclear Metrics Added descriptive sub-labels to all dashboard cards.
Failing Infrastructure Paths Corrected recursive path mapping in infrastructure-audit.test.js.

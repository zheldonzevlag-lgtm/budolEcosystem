BudolPay v2.4.7: Map Search & Pin-Sync Enhancement

Version: 2.4.7

Mobile Version: 1.3.83+184

Date: 2026-04-12

Category: Release / Mobile UX

Purpose

The primary objective of this release is to introduce a centralized search interface within the Map Picker, allowing users to find specific addresses via text input and synchronously pinning them on the map.

Rationale

While Phase 1 (v2.4.6) implemented address resolution from coordinates, users requested the ability to "search first then pin." This update closes the loop by providing bidirectional synchronization between text search and geographic pinning.

Scope

  • Implemented the MapPicker search bar with auto-forward geocoding.
  • Enabled Pin-Sync logic: dragging the map automatically updates the search input with the human-readable address.
  • Compiled and completed Flutter Mobile application release `v1.3.83` (1.3.83+184).
  • Transferred the released artifact to `\android-installer\budolPay 1.3.83.apk`.

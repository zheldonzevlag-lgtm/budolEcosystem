v2.4.7: Test Suite Stabilization & AI Anti-Spam Engine Release

Version: v2.4.7 Date: 2026-04-13 Author: Antigravity (AI Auditor)

Release Purpose

The v2.4.7 release completes the institutional compliance gate by:

  • Stabilizing all 17 Jest test suites to pass or skip gracefully (0 failures)
  • Resolving cross-platform build blockers (admin package.json, Windows/Vercel parity)
  • Implementing the DRS Engine Heartbeat background telemetry
  • Finalizing Admin Dashboard email login and OTP flows
  • Establishing institutional test patterns for Node.js 18+ IPv6, ESM/CJS, and service availability

Technical Highlights

AI Anti-Spam Engine (auth-service)

Registration payloads are now scored by the EWMA-based AI spam detection engine. Disposable domains and high-entropy username patterns are blocked with HTTP 403. Tests confirm integration via spam_prevention.test.js.

DRS Engine Heartbeat (transaction-service)

A non-blocking background timer using .unref() updates system health telemetry in the SystemSetting table every 30 seconds, enabling the Admin Dashboard DRS shield to display live status.

payment-gateway-service Utility Extraction

Created api/utils.js to host generateSecureReferenceId independently. This enables unit-testing the utility without triggering any database or server side effects.

Admin Dashboard Email Login

Verified that SSO_MANAGED users can authenticate via email/password → OTP flow on the Admin Dashboard, proxied through budolID SSO.

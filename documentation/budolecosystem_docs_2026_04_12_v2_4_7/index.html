v2.4.7: Admin Dashboard Stabilization & Telemetry Release

Version: v2.4.7 Date: 2026-04-12 Author: Antigravity (AI Auditor)

Release Purpose

The v2.4.7 release focuses on the technical stabilization of the Admin Dashboard "Release Gate" by resolving remaining failing test suites and implementing institutional-grade system health telemetry (DRS Engine Heartbeat).

Implementation Status

✔ Phase 1: Test Suite Stabilization (17/17 Passed)
✔ Phase 2: DRS Engine Heartbeat Implementation
✔ Phase 3: Dashboard UI Density Optimization (10px standard)
✔ Phase 4: ESM/CJS Cross-Workspace Compatibility Fixes
⏳ Phase 5: Documentation & Institutional Audit (In-Progress)

Technical Highlights

DRS Engine Heartbeat

Implemented a non-blocking background telemetry mechanism in the transaction-service that updates system health every 30 seconds. Uses .unref() to ensure clean test exits.

UI High-Density Compliance

Refactored the Compliance Shield and main metrics grid to meet institutional standards for information density, enforcing a 10px font size for data labels and sub-labels.

Developer Manual: Map Search & Geocoding Sync (v2.4.7)

Technical Overview

This update enhances the Map Picker by introducing bidirectional synchronization between the visual map state and a textual search interface. It leverages both forward geocoding (search string to LatLng) and reverse geocoding (LatLng to address string).

Implementation Details

Bidirectional Sync Logic

Located in: map_picker.dart

The state management centers around three primary reactive pipelines:

  1. Search Trigger (Forward): When onSubmitted is called on the TextField, locationFromAddress() resolves the query. The MapController then moves the viewport, and the internal state updates.
  2. Tap/Drag Trigger (Reverse): When onTap or a controller move completes, placemarkFromCoordinates() is called. The resulting address fragments are joined and set as the text for the _searchController.
  3. Loading States: _isSearching provides UI feedback via a CircularProgressIndicator embedded in the TextField prefix/suffix.

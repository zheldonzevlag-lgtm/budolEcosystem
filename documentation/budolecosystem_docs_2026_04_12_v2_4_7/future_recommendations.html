Strategic Roadmap & Recommendations: v2.4.7

Priority: Medium-Long Term Date: 2026-04-12

1. Technical Debt & ESM Migration

Dual-Emission for budolshap

The current workaround for realtime.test.js inlines logic to bypass ESM parsing issues in CommonJS Jest environments. For v2.5.0, we recommend configuring budolshap to build both ESM and CJS modules, ensuring standard import/export functionality across the ecosystem without brittle inlining.

2. UI/UX Evolution

Adaptive Density Mode

While the 10px high-density layout satisfies technical audits, users without high-resolution displays may experience eye strain. We recommend implementing a "Toggle Density" feature (Institutional vs. Standard) to improve accessibility while maintaining compliance when required.

3. Advanced Telemetry

Push-Based Health Monitoring

The current 30-second heartbeat uses a polling mechanism in the dashboard. Transitioning to a WebSocket-based push (via the already implemented Realtime Channel) would provide sub-second latency for "Offline" alerts, improving the RTO (Recovery Time Objective) for the NOC team.

4. Security & Compliance

Automated Penetration Testing

Building on the spam_prevention.test.js success, we recommend integrating an automated OWASP ZAP scan into the CI/CD pipeline to detect surface-level vulnerabilities before they reach the "Release Gate."

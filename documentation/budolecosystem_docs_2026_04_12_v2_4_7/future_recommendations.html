Future Enhancements & Recommendations (v2.4.7)

Identified Technical Debt & Next Steps

  • Backend E2E Tests: The existing failures in realtime.test.js and spam_prevention.test.js discovered during the v2.4.6 cycle remain high priority technical debt. These must be addressed before the next major release (v2.5.0).
  • Dynamic Map Provider Switching: Currently, MapPicker defaults back to OSM tiles if other providers are selected. Implementing full support for Google/Radar tile layers via platform channels is recommended.
  • Offline Map Support: Implement tile caching to allow map interaction in zero-connectivity scenarios, though geocoding will still require network resolution.

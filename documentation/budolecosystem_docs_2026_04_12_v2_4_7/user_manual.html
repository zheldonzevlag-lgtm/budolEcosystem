User Manual: Navigating the v2.4.7 Dashboard

Role: Admin Dashboard User Version: 2.4.7

1. Enhanced Metrics Grid

The dashboard has been upgraded with a high-density metrics grid designed for institutional monitoring. The new 10px standard ensures maximum information visibility.

New Card Layouts

  • Compliance Shield: Shows real-time PCI DSS and BSP compliance status in a compact 4-column grid.
  • DRS Status: A dedicated indicator for the Dynamic Risk Scoring Engine health.
  • Fraud Analytics: Real-time trending indicators for suspicious activity.

2. Understanding DRS Engine Status

On the top-left of the dashboard, you will find the DRS Engine status. This is the heart of our security system.

  • ACTIVE (Green): Risk scoring is running normally. No action required.
  • DELAYED (Yellow): Risk scoring is slightly delayed. Monitor closely.
  • OFFLINE (Red): RISK ENGINE IS DOWN. Contact IT immediately. Manual approvals may be required for all transactions.

3. Accessibility & Font Scaling

This release uses a standardized high-density layout. If text is too small, use your browser's zoom feature (Ctrl + '+'). Standard UI font size for data labels is fixed at 10px for technical audit compliance.

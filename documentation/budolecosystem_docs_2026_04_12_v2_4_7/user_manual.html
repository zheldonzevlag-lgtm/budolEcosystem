User Manual: Pinning Your Address with Search

The Map Picker now includes a powerful search feature to help you locate your address faster.

  1. Tap Pin Address on the Verification Screen.
  2. Search: Use the search bar at the top to type your street or village name.
  3. Confirm: The map will move to the result. You can then drag the map to fine-tune the pin. The address text will update automatically.
  4. Tap Confirm to save the location.

System Admin Manual: Geocoding & Sync (v2.4.7)

The Search functionality uses the geocoding Flutter package, which interface with system-level geocoding engines.

  • Forward Geocoding: Converts search strings to coordinates.
  • Reverse Geocoding: Converts pin coordinates to street addresses.
  • Compliance: No sensitive location data is stored in server logs; it is only used locally to populate the verification form.

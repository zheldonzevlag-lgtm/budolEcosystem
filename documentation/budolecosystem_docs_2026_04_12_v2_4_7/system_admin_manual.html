System Admin Manual: Monitoring & Health

Role: Administrator / NOC Version: 2.4.7

1. DRS Engine Monitoring

The Dynamic Risk Scoring (DRS) Engine status is now tracked via a centralized heartbeat system visible on the Admin Dashboard.

Interpreting the Status Indicators

Status Color Meaning
ACTIVE Green System heartbeat received within the last 120 seconds. Risk analysis is running.
DELAYED Yellow No heartbeat for >2 minutes. Transaction processing may be slowed.
OFFLINE Red System heartbeat failed for >5 minutes. Critical alert triggered.

3. Troubleshooting

Dashboard showing OFFLINE?

  1. Verify transaction-service is running.
  2. Check database connectivity (prisma db pull test).
  3. Ensure SystemSetting table is not locked.

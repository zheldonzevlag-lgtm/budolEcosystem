System Admin Manual: v2.4.7

Version: v2.4.7 Date: 2026-04-13 Audience: System Administrators / DevOps

Service Start Procedure

All services are started from the ecosystem root using the unified start script:

cd D:\IT Projects\clone\budolEcosystem
npm start

This runs all microservices concurrently. Verify each service starts on its designated port (see architecture table in Developer Manual).

DRS Engine Heartbeat Monitoring

The DRS (Dynamic Risk Scoring) Engine Heartbeat is a background telemetry process running in transaction-service. It writes a health pulse to the SystemSetting table every 30 seconds.

Verifying Heartbeat is Active

-- Run in PostgreSQL console
SELECT key, value, "updatedAt"
FROM "SystemSetting"
WHERE key = 'drs_heartbeat_last_ping'
ORDER BY "updatedAt" DESC LIMIT 1;

Expected: updatedAt should be within the last 60 seconds. If older than 2 minutes, the transaction-service may have crashed.

Restarting the Heartbeat

cd budolpay-0.1.0/services/transaction-service
node index.js

Payment Gateway Service

Starting the Service

cd budolpay-0.1.0/services/payment-gateway-service
node api/index.js

Health Check

curl http://127.0.0.1:8004/health

Expected response: {"status":"Payment Gateway Service is healthy","timestamp":"..."}

Important: body-parser Configuration (v2.4.7)

In v2.4.7, the body-parser was updated to accept application/json with any charset. If upgrading manually, ensure api/index.js uses:

router.use(bodyParser.json({
  type: (req) => req.headers['content-type']?.startsWith('application/json')
}));

Running Integration Tests

Unit / Offline Tests (no services required)

cd budolpay-0.1.0/scripts/test_scripts
npx jest --forceExit

Expected: 16 pass, 1 skip (payment-security, requires live gateway)

Full Integration Tests (all services must be running)

# 1. Start all services
npm start

# 2. Run tests
cd budolpay-0.1.0/scripts/test_scripts
npx jest --forceExit

Expected with all services up: 17 pass, 0 skip, 0 fail

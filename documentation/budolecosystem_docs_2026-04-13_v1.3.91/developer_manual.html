Developer Manual: v1.3.91

Technical specifications for the Modern Ruby branding restoration.

1. Global Branding Tokens

The core color palette is centralized in brand_colors.dart. All UI components must use these tokens rather than hardcoded hex values.

static const Color primary = Color(0xFFF43F5E); // Budol Red
static const Color primaryDark = Color(0xFF991B1B); // Deep Ruby
static const Color surface = Color(0xFF0F172A); // Midnight Slate

2. Glassmorphism Mesh Backgrounds

Implemented in login_screen.dart and registration_screen.dart. Uses a manual `CustomPainter` to render high-performance radial mesh gradients.

// Example Mesh Gradient Implementation
canvas.drawCircle(Offset(size.width * 0.2, size.height * 0.1), 300, Paint()..color = BrandColors.primary.withOpacity(0.15)..maskFilter = MaskFilter.blur(BlurStyle.normal, 100));

3. Balance Card Architecture

Visible in home_screen.dart. Rebuilt to support frosted-glass effects with a red accent overlay.

// Refactored Balance Card Stack
Stack(children: [ Container(height: 180, decoration: BoxDecoration(gradient: LinearGradient(...))), _buildBalanceCard(...) ])

4. Institutional Standards

  • Contrast: All text on Ruby backgrounds must meet WCAG 2.1 Level AA (4.5:1 ratio).
  • Focus Indicators: Inputs use a 2.5px BrandColors.primary border when focused.

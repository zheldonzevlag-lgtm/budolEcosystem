System Admin Manual - v1.3.90

Branding Deployment

Admin must ensure that all production instances of budolPayMobile are updated to v1.3.90 to maintain visual consistency across the ecosystem. Version mismatch may lead to unprofessional "Mixed Brand" appearance.

Identity Verification Management

The new branding introduces more prominent "Verification Required" statuses. Admins should monitor KYC queues in the ComplianceBoard as users are more likely to interact with the new high-visibility Verification Card.

Mobile Distribution

The budolPay 1.3.90.apk replaces all previous versions. Admins should deploy this to the distribution server and force-update legacy clients.

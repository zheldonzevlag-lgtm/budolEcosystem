Branding Tokens

All colors are centralized in brand_colors.dart. Developers MUST NOT use hardcoded hex values in UI builders.

// lib/utils/brand_colors.dart
static const Color primary = Color(0xFF0F172A); // Midnight Navy
static const Color accent = Color(0xFF2DD4BF); // Vibrant Teal

Theme Parity Logic

Ensure all components use Theme.of(context).colorScheme to automatically adapt between Light and Dark Sovereign modes.

// Component Style Example
color: Theme.of(context).colorScheme.primary, // Resolves to Midnight Navy
